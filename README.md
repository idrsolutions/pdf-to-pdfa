# Convert PDF files to PDF/A

JPedal is a pure Java PDF library to provide Java Developers with the
abilities to work with PDF files directly from Java. JPedal makes a
wide range of PDF processing tasks simple to solve in a few lines of
code.

JPedal allows for easy conversion of PDF files to PDF/A-3b, the ISO
standard for long-term archiving of documents. See the provided
example code for how to perform the conversion.

Learn more about [JPedal](https://www.idrsolutions.com/jpedal/).
